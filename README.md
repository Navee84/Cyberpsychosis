# Cyberpsychosis
Mon projet final pour la NSI

## Concept
Cyberpsychosis est un rogue like, fast action shooter, en vue top down, se déroulant sur une carte limitée. Le but principal est de challenger le joueur en proposant un jeu dynamique et rapide. Le but principal du joueur est de survivre face à des ennemis de plus en plus puissants, pour inévitablement perdre. Le but secondaire pour le joueur est de marquer le plus haut score possible.
